# Consolemania Turnier-Timer

Rundentimer für TCG-Turniere bei Consolemania in Aschaffenburg: Pokémon, Magic: The Gathering und Star Wars: Unlimited.

Live: https://consolemania-timer.github.io

- Bis zu 4 Timer gleichzeitig, Presets pro Spiel, Extra-Züge bzw. letzte Phase nach Ablauf
- Warntöne (8-Bit, im Browser erzeugt), Vorlauf-Countdown, Vollbild, Tastenkürzel
- Reine statische Seite ohne Server, Cookies oder Tracking; Einstellungen bleiben im Browser

Tastenkürzel: Leertaste Start/Pause · N nächster Zug · R Reset · +/− Minute · F Vollbild · 1–4 Timer wählen
